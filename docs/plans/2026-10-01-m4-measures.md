> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Répondre à « est-ce que ça passe ? ». Pour cela :
- les cotes libres s'affichent en direct autour du meuble sélectionné, déplacé ou en cours de pose ;
- un outil de mesure libre, avec magnétisme ;

**Architecture:**

- **Assemblage** : `main.gd` route Tab, O, P et M, et affiche une indication du mode actif en bas de l'écran.

## Choix et écarts par rapport à la spec

1. **Cotes en direct** : elles s'affichent aussi pendant la pose d'un meuble (aperçu translucide), pas seulement pour le meuble sélectionné ou déplacé. Chaque côté envoie 3 rayons (aux deux bouts, en retrait de 2 cm, et au milieu), et la distance la plus courte l'emporte. Rien n'est affiché au-delà de 10 m, ni si le côté touche déjà un obstacle.
2. **Tab** bascule entre la vue plan et la vue orbitale. O ramène toujours à la vue orbitale. En vue plan, tous les glisser (clic droit, clic molette, deux doigts) déplacent la vue, car il n'y a pas de rotation. La transition de 0,4 s se fait en perspective, puis passe en orthographique à l'arrivée.
3. **Calque** : il est activé par défaut, visible seulement en vue plan, et P l'affiche ou le masque. L'image est cherchée à côté du fichier projet, puis dans `res://data/`. Un projet issu du log 16 et enregistré ailleurs garde donc son calque.
4. **Mesure libre** : M l'active ou la désactive en gardant les mesures. Échap efface toutes les mesures et quitte l'outil. Ouvrir un autre projet efface aussi les mesures. Une indication en bas de l'écran rappelle les touches.
5. **Masquage des murs** : il est suspendu en vue plan (tous les murs debout) et recalculé au retour en vue orbitale.

## Review Focus

1. **Meuble qui touche déjà un mur ou un autre meuble** : pas de cote de 0 cm affichée de ce côté. Tests : `test_overlap_counts_as_zero` (Task 1) et `test_clearance_view_hides_touching_sides_and_clears` (Task 2).
2. **Mur en biais près d'un meuble tourné** : la cote suit les côtés du meuble, pas les axes x et z. Test : `test_rotation_turns_the_sides` (Task 1).
3. **Deux clics au même endroit en mode mesure** : aucune mesure de 0 cm. Test : `test_clicking_twice_on_the_same_point_adds_nothing` (Task 3).
4. **Projet sans calque, ou image introuvable** : rien ne s'affiche, et sans erreur. Tests : `test_project_without_underlay_shows_nothing` et `test_missing_image_shows_nothing` (Task 5).
5. **Mesures d'un ancien projet** restées affichées sur le nouveau : elles sont effacées à l'ouverture. Test : `test_opening_another_project_clears_measurements` (Task 6).

`src/model/clearance.gd` :

```gdscript
class_name Clearance
extends RefCounted
## Free space around a furniture footprint: for each of its four sides, the
## distance to the first wall or other piece of furniture, found by casting 2D
## rays from the side outwards.

const SIDES: PackedStringArray = ["front", "back", "left", "right"]
## Rays further than this report nothing (open space).
const MAX_RANGE := 10.0
## Rays start this far inside the side's ends, so touching neighbours at a
## corner do not count as zero clearance.
const CORNER_INSET := 0.02
## Per side, in the item's local frame (x = width axis, y = towards the front):
## [outward normal, direction along the side].
const _SIDE_FRAMES := {
	"front": [Vector2(0, 1), Vector2(1, 0)],
	"back": [Vector2(0, -1), Vector2(1, 0)],
	"left": [Vector2(-1, 0), Vector2(0, 1)],
	"right": [Vector2(1, 0), Vector2(0, 1)],
}


## Returns {side: {"distance": float, "from": Vector2, "to": Vector2}} for each
## side that meets something within MAX_RANGE. `obstacles` are footprints
## (walls and other furniture) as PackedVector2Array polygons.
static func free_distances(pos: Vector2, size: Vector3, rotation_deg: float,
		obstacles: Array[PackedVector2Array]) -> Dictionary:
	var result := {}
	var hw := size.x / 2.0
	var hd := size.z / 2.0
	for side in SIDES:
		var normal_local: Vector2 = _SIDE_FRAMES[side][0]
		var along_local: Vector2 = _SIDE_FRAMES[side][1]
		var across_x := absf(normal_local.x) > 0.0
		var half_length := hd if across_x else hw
		var offset := hw if across_x else hd
		var outward := Placement.to_world(Vector2.ZERO, rotation_deg, normal_local)
		var best := {}
		var inset := maxf(half_length - CORNER_INSET, 0.0)
		for t in [-inset, 0.0, inset]:
			var origin := Placement.to_world(pos, rotation_deg, normal_local * offset + along_local * t)
			var hit := _cast(origin, outward, obstacles)
			if hit.is_empty():
				continue
			if best.is_empty() or hit.distance < best.distance:
				best = hit
		if not best.is_empty():
			result[side] = best
	return result


## The obstacles around an item: every wall footprint and every other item's footprint.
static func obstacles_for(project: ProjectData, ignore_id: String) -> Array[PackedVector2Array]:
	var obstacles: Array[PackedVector2Array] = []
	for footprint in Geometry.wall_footprints(project).values():
		obstacles.append(footprint)
	for item in project.furniture:
		if item.id != ignore_id:
			obstacles.append(Placement.footprint(item.pos, item.size, item.rotation_deg))
	return obstacles


static func _cast(origin: Vector2, direction: Vector2, obstacles: Array[PackedVector2Array]) -> Dictionary:
	var far := origin + direction * MAX_RANGE
	var best_distance := INF
	var best_point := Vector2.ZERO
	for polygon in obstacles:
		if Geometry2D.is_point_in_polygon(origin, polygon):
			return {"distance": 0.0, "from": origin, "to": origin}
		for i in polygon.size():
			var hit = Geometry2D.segment_intersects_segment(origin, far, polygon[i], polygon[(i + 1) % polygon.size()])
			if hit != null and origin.distance_to(hit) < best_distance:
				best_distance = origin.distance_to(hit)
				best_point = hit
	if best_distance == INF:
		return {}
	return {"distance": best_distance, "from": origin, "to": best_point}
```

`src/model/measure_snap.gd` :

```gdscript
class_name MeasureSnap
extends RefCounted
## Magnetism for the free measuring tool: corners first (wall nodes, wall
## footprint corners, furniture corners), then edges (wall faces, furniture
## sides), otherwise the point itself.

const RADIUS := 0.15


static func snap(point: Vector2, project: ProjectData, radius: float = RADIUS) -> Vector2:
	var polygons: Array[PackedVector2Array] = []
	for footprint in Geometry.wall_footprints(project).values():
		polygons.append(footprint)
	for item in project.furniture:
		polygons.append(Placement.footprint(item.pos, item.size, item.rotation_deg))
	var corners := PackedVector2Array()
	for node in project.nodes:
		corners.append(node.pos)
	for polygon in polygons:
		corners.append_array(polygon)
	var best := point
	var best_distance := radius
	for corner in corners:
		var distance := point.distance_to(corner)
		if distance <= best_distance:
			best_distance = distance
			best = corner
	if best != point:
		return best
	best_distance = radius
	for polygon in polygons:
		for i in polygon.size():
			var on_edge := Geometry2D.get_closest_point_to_segment(point, polygon[i], polygon[(i + 1) % polygon.size()])
			var distance := point.distance_to(on_edge)
			if distance <= best_distance:
				best_distance = distance
				best = on_edge
	return best
```

```gdscript
func set_points(a: Vector2, b: Vector2) -> void:
	var length := a.distance_to(b)
	visible = length > 0.0
	if not visible:
		return
	var mid := (a + b) / 2.0
	var dir := (b - a) / length
	var yaw := -dir.angle()
	_place(_bar, mid, yaw, Vector3(length, THICKNESS, THICKNESS))

	for i in 2:
		var end := a if i == 0 else b
		_place(_ticks[i], end, -across.angle(), Vector3(TICK_LENGTH, THICKNESS, THICKNESS))
	_label.text = text_for(length)
	_label.position = Vector3(mid.x, HEIGHT + LABEL_LIFT, mid.y)
```

```gdscript
	var item: FurnitureItem = store.get_furniture(selected_id())
	if item == null:
		return
	if not item.pos.is_equal_approx(_drag_pos) or not is_equal_approx(item.rotation_deg, _drag_rotation):
		store.update_furniture(item.id, {"pos": _drag_pos, "rotation_deg": _drag_rotation})
	get_viewport().set_input_as_handled()


func _on_key(event: InputEventKey) -> void:
	var command := event.is_command_or_control_pressed()
	if command and event.keycode == KEY_Z:
		if _dragging:
			return  # The release would overwrite whatever the undo reverted.
		if event.shift_pressed:
			store.redo()
		else:
			store.undo()
	elif command and event.keycode == KEY_D:
		if selected_id() != "" and not _dragging:
			_select(store.duplicate_furniture(selected_id()))
	elif event.keycode == KEY_ESCAPE:
		if _placing != null:
			cancel_placement()
		else:
			_select("")
	elif event.keycode == KEY_R and _placing != null:
		_user_rotation = fposmod(_user_rotation + ROTATE_STEP_DEG, 360.0)
		_update_ghost(_last_mouse, false)
	elif event.keycode == KEY_R and selected_id() != "" and not _dragging:
		_rotate_selected(ROTATE_STEP_DEG)
	elif event.keycode in [KEY_DELETE, KEY_BACKSPACE] and selected_id() != "" and not _dragging:
		store.remove_furniture(selected_id())
	else:
		return
	get_viewport().set_input_as_handled()


func _rotate_selected(step_deg: float) -> void:
	var item: FurnitureItem = store.get_furniture(selected_id())
	store.update_furniture(item.id, {"rotation_deg": fposmod(item.rotation_deg + step_deg, 360.0)})


func _update_ghost(screen_pos: Vector2, free_move: bool) -> void:
	var ground = _ground_point(screen_pos)
	if ground == null:
		return
	var placed := _snap(ground, _placing.size, _user_rotation, free_move)
	_ghost_pos = placed.pos
	_ghost_rotation = placed.rotation_deg
	view.move_ghost(_ghost_pos, _ghost_rotation)
	focus_changed.emit("", _ghost_pos, _placing.size, _ghost_rotation)


func _place_ghost() -> void:
	var item := _placing.make_item(store.next_furniture_id(), _ghost_pos)
	item.rotation_deg = _ghost_rotation
	cancel_placement()
	if store.add_furniture(item):
		_select(item.id)


## Grid snapping (unless `free_move`), then wall snapping which may also turn the item.
func _snap(pos: Vector2, size: Vector3, rotation_deg: float, free_move: bool) -> Dictionary:
	var snapped := pos if free_move else Placement.snap_to_grid(pos)
	var wall := Placement.snap_to_wall(store.project, snapped, size)
	if wall.is_empty():
		return {"pos": snapped, "rotation_deg": rotation_deg}
	return wall


## Where the mouse ray meets the floor (y = 0), or null.
func _ground_point(screen_pos: Vector2) -> Variant:
	var hit = Plane(Vector3.UP, 0).intersects_ray(camera.project_ray_origin(screen_pos),
		camera.project_ray_normal(screen_pos))
	return null if hit == null else Vector2(hit.x, hit.z)


func _select(id: String) -> void:
	view.set_selected(id)
	_sync_selection()


## Announces the view's selection if it changed (e.g. the item was deleted or undone).
func _sync_selection() -> void:
	var current := view.selected_id()
	if current == _selection:
		return
	if current == "":
		_dragging = false
	_selection = current
	selection_changed.emit(current)
	_emit_focus()


## Re-announces the focus from the current state (ghost, else selection).
func _emit_focus() -> void:
	if _placing != null:
		focus_changed.emit("", _ghost_pos, _placing.size, _ghost_rotation)
		return
	var item: FurnitureItem = store.get_furniture(view.selected_id()) if view.selected_id() != "" else null
	if item == null:
		focus_cleared.emit()
	else:
		focus_changed.emit(item.id, item.pos, item.size, item.rotation_deg)


func _on_furniture_removed(_id: String) -> void:
	_sync_selection()


func _on_furniture_changed(id: String) -> void:
	if id == view.selected_id() and not _dragging:
		_emit_focus()


func _on_project_loaded() -> void:
	cancel_placement()
	_sync_selection()
```

```gdscript
class_name MeasureTool
extends Node
## Free measuring (M): click A, then B; each pair stays drawn until Échap,
## which clears them all and leaves the tool. Points snap to corners and
## edges. Measurements are not saved in the project.

signal active_changed(active: bool)

var store: Node
var camera: Camera3D
var _active := false
var _start = null  # Vector2 of the pending first point, or null
var _measurements: Array = []  # [Vector2 a, Vector2 b] pairs
var _preview: DimensionLine
var _layer: Node3D


## `layer` receives the dimension lines (a Node3D in the 3D scene).
func setup(p_store: Node, p_camera: Camera3D, layer: Node3D) -> void:
	store = p_store
	camera = p_camera
	_layer = layer
	_preview = DimensionLine.new()
	_preview.name = "Preview"
	_preview.visible = false
	_layer.add_child(_preview)


func is_active() -> bool:
	return _active


func set_active(active: bool) -> void:
	if active == _active:
		return
	_active = active
	if not active:
		_start = null
		_preview.visible = false
	active_changed.emit(active)


func toggle() -> void:
	set_active(not _active)


func measurements() -> Array:
	return _measurements.duplicate()


## Removes every measurement and leaves the tool.
func clear_all() -> void:
	_measurements.clear()
	for child in _layer.get_children():
		if child != _preview:
			_layer.remove_child(child)
			child.queue_free()
	set_active(false)


func _unhandled_input(event: InputEvent) -> void:
	if not _active:
		return
	if event is InputEventMouseMotion and _start != null:
		var point = _snapped_ground(event.position)
		if point != null:
			_preview.set_points(_start, point)
	elif event is InputEventMouseButton and event.pressed and event.button_index == MOUSE_BUTTON_LEFT:
		var point = _snapped_ground(event.position)
		if point != null:
			_click(point)
		get_viewport().set_input_as_handled()
	elif event is InputEventKey and event.pressed and not event.echo and event.keycode == KEY_ESCAPE:
		clear_all()
		get_viewport().set_input_as_handled()


func _click(point: Vector2) -> void:
	if _start == null:
		_start = point
		return
	if not point.is_equal_approx(_start):
		_measurements.append([_start, point])
		var line := DimensionLine.new()
		line.name = "Measure%d" % _measurements.size()
		_layer.add_child(line)
		line.set_points(_start, point)
	_start = null
	_preview.visible = false


func _snapped_ground(screen_pos: Vector2) -> Variant:
	var hit = Plane(Vector3.UP, 0).intersects_ray(camera.project_ray_origin(screen_pos),
		camera.project_ray_normal(screen_pos))
	if hit == null:
		return null
	return MeasureSnap.snap(Vector2(hit.x, hit.z), store.project)
```

```gdscript
const FOCUS_SECONDS := 0.4
const VIEW_TRANSITION_SECONDS := 0.4
## Height of the plan camera above the target; far above any wall.
const PLAN_HEIGHT := 60.0
## Looking down (-y) with the screen's up towards -z.
const PLAN_BASIS := Basis(Vector3(1, 0, 0), Vector3(0, 0, -1), Vector3(0, 1, 0))

## Receives the horizontal viewing direction every frame (WorldView.update_cutaway).
signal heading_changed(forward: Vector2)
signal view_mode_changed(plan: bool)

var orbit := OrbitState.new()
var _project: ProjectData
var _focus_tween: Tween
var _plan := false
var _view_tween: Tween


func frame_project(project: ProjectData) -> void:
	_project = project
	var center := Cutaway.apartment_center(project)
	orbit.target = Vector3(center.x, 0, center.y)
	_apply()


func _ready() -> void:
	_apply()


func is_plan_mode() -> bool:
	return _plan


## Switches between the orbit view and the plan view, with a short camera move.
func set_plan_mode(plan: bool, animate: bool = true) -> void:
	if plan == _plan:
		return
	_plan = plan
	if _view_tween:
		_view_tween.kill()
	var target := _pose()
	if not animate or not is_inside_tree():
		_finish_view_change()
	else:
		# The move happens in perspective; the plan switches to orthographic on arrival.
		projection = Camera3D.PROJECTION_PERSPECTIVE
		_view_tween = create_tween().set_trans(Tween.TRANS_CUBIC).set_ease(Tween.EASE_IN_OUT)
		_view_tween.tween_property(self, "transform", target, VIEW_TRANSITION_SECONDS)
		_view_tween.tween_callback(_finish_view_change)
	view_mode_changed.emit(plan)


func toggle_plan_mode() -> void:
	set_plan_mode(not _plan)


func _process(_delta: float) -> void:
	if not _plan:
		heading_changed.emit(orbit.forward_2d())


func _unhandled_input(event: InputEvent) -> void:
	if event is InputEventMouseMotion:
		var panning: bool = event.button_mask & MOUSE_BUTTON_MASK_MIDDLE \
				or (event.button_mask & MOUSE_BUTTON_MASK_RIGHT and event.shift_pressed)
		if _plan and event.button_mask & (MOUSE_BUTTON_MASK_RIGHT | MOUSE_BUTTON_MASK_MIDDLE):
			_pan_plan(event.relative)
		elif panning:
			_pan(event.relative, PAN_M_PER_PX_PER_M)
		elif event.button_mask & MOUSE_BUTTON_MASK_RIGHT:
			orbit.rotate(-event.relative.x * ROTATE_DEG_PER_PX, -event.relative.y * ROTATE_DEG_PER_PX)
			_apply()
	elif event is InputEventPanGesture:
		if _plan:
			_pan_plan(event.delta * SCROLL_PLAN_PX_PER_UNIT)
		elif event.shift_pressed:
			_pan(event.delta, SCROLL_PAN_M_PER_UNIT_PER_M)
		else:
			orbit.rotate(-event.delta.x * SCROLL_ROTATE_DEG_PER_UNIT, -event.delta.y * SCROLL_ROTATE_DEG_PER_UNIT)
			_apply()
	elif event is InputEventMagnifyGesture:
		orbit.zoom((event.factor - 1.0) * PINCH_ZOOM_SENSITIVITY)
		_apply()
	elif event is InputEventMouseButton and event.pressed:
		match event.button_index:
			MOUSE_BUTTON_WHEEL_UP:
				orbit.zoom(ZOOM_STEP)
				_apply()
			MOUSE_BUTTON_WHEEL_DOWN:
				orbit.zoom(-ZOOM_STEP)
				_apply()
			MOUSE_BUTTON_LEFT:
				if event.double_click:
					_focus_room_under(event.position)


func _pan(screen_delta: Vector2, metres_per_unit_per_metre: float) -> void:
	var scale := metres_per_unit_per_metre * orbit.distance
	orbit.pan(Vector2(-screen_delta.x, screen_delta.y) * scale)
	_apply()


func _focus_room_under(screen_point: Vector2) -> void:
	if _project == null:
		return
	var hit = Plane(Vector3.UP, 0).intersects_ray(project_ray_origin(screen_point), project_ray_normal(screen_point))
	if hit == null:
		return
	var point := Vector2(hit.x, hit.z)
	for room in _project.rooms:
		var polygon := Geometry.room_polygon(_project, room)
		if Geometry2D.is_point_in_polygon(point, polygon):
			var c := Geometry.polygon_centroid(polygon)
			if _focus_tween:
				_focus_tween.kill()
			_focus_tween = create_tween()
			_focus_tween.tween_method(_set_target, orbit.target, Vector3(c.x, 0, c.y), FOCUS_SECONDS)
			return


## Drags the plan under the cursor: content follows the pointer.
func _pan_plan(screen_delta: Vector2) -> void:
	var metres_per_px := size / maxf(get_viewport().get_visible_rect().size.y, 1.0)
	orbit.target += Vector3(-screen_delta.x, 0, -screen_delta.y) * metres_per_px
	_apply()


func _set_target(value: Vector3) -> void:
	orbit.target = value
	_apply()


func _apply() -> void:
	if _view_tween and _view_tween.is_running():
		return
	transform = _pose()
	if _plan:
		size = orbit.distance


func _pose() -> Transform3D:
	if _plan:
		return Transform3D(PLAN_BASIS, orbit.target + Vector3.UP * PLAN_HEIGHT)
	return orbit.camera_transform()


func _finish_view_change() -> void:
	_view_tween = null  # still "running" while its final callback executes
	projection = Camera3D.PROJECTION_ORTHOGONAL if _plan else Camera3D.PROJECTION_PERSPECTIVE
	_apply()
```

```gdscript
extends Node3D
## Rebuilds walls and floors when a project is loaded, and lowers the walls
## that hide the inside from the orbit camera.

const CUTAWAY_TWEEN_SECONDS := 0.25

var cutaway_mode := Cutaway.Mode.AUTO
var _project: ProjectData
var _walls: Node3D
var _floors: Node3D
var _center := Vector2.ZERO
var _last_forward := Vector2.ZERO
var _lowered := {}  # wall id -> bool, to tween only on change
var _suspended := false  # plan view: every wall stands at full height
var _tweens := {}  # wall id -> Tween, so a new move replaces the running one


func show_project(project: ProjectData) -> void:
	_project = project
	for child in get_children():
		remove_child(child)
		child.queue_free()
	_floors = FloorBuilder.build(project)
	_walls = WallBuilder.build(project)
	add_child(_floors)
	add_child(_walls)
	_center = Cutaway.apartment_center(project)
	_lowered.clear()
	_tweens.clear()
	_last_forward = Vector2.ZERO


func cycle_cutaway_mode() -> void:
	cutaway_mode = (cutaway_mode + 1) % Cutaway.Mode.size() as Cutaway.Mode
	_lowered.clear()
	_last_forward = Vector2.ZERO


## While suspended (plan view), every wall stands at full height and camera
## headings are ignored; resuming recomputes the cutaway on the next heading.
func set_cutaway_suspended(suspended: bool) -> void:
	_suspended = suspended
	_lowered.clear()
	_last_forward = Vector2.ZERO
	if suspended and _project != null:
		for wall in _project.walls:
			var node := _walls.get_node_or_null(NodePath(wall.id)) as Node3D
			if node != null:
				_tween_wall(wall.id, node, 1.0)


## Called every frame by the camera rig with its horizontal viewing direction.
func update_cutaway(camera_forward: Vector2) -> void:
	if _project == null or _suspended or camera_forward.is_equal_approx(_last_forward):
		return
	_last_forward = camera_forward
	for wall in _project.walls:
		var node := _walls.get_node_or_null(NodePath(wall.id)) as Node3D
		if node == null:
			continue
		var lowered := Cutaway.is_lowered(_project.get_plan_node(wall.a).pos,
			_project.get_plan_node(wall.b).pos, _center, camera_forward)
		if _lowered.get(wall.id) == lowered:
			continue
		_lowered[wall.id] = lowered
		_tween_wall(wall.id, node, Cutaway.target_scale(cutaway_mode, lowered, wall.height))


func _tween_wall(wall_id: String, node: Node3D, target_scale: float) -> void:
	var running: Tween = _tweens.get(wall_id)
	if running:
		running.kill()
	var tween := create_tween()
	tween.tween_property(node, "scale:y", target_scale, CUTAWAY_TWEEN_SECONDS)
	_tweens[wall_id] = tween
```

```gdscript
class_name UnderlayView
extends MeshInstance3D
## The architect's plan image laid on the floor, scaled by the project's
## `underlay`, to check the modelled walls. Shown only in plan view, when the
## user has it switched on (P).

const HEIGHT := 0.01
const OPACITY := 0.6
## Bundled plans are found here when the image is not next to the project file.
const BUNDLED_DIR := "res://data"

var enabled := true
var _plan_view := false
var _has_image := false


func _init() -> void:
	name = "Underlay"
	visible = false


## Loads the project's underlay image, looked up next to the project file and
## then among the bundled plans. Returns false when there is none to show.
func show_project(project: ProjectData, project_path: String) -> bool:
	_has_image = false
	mesh = null
	if project.underlay != null:
		var texture := _load_texture(project.underlay.image, project_path)
		if texture != null:
			_build(project.underlay, texture)
			_has_image = true
	_refresh()
	return _has_image


func set_plan_view(plan_view: bool) -> void:
	_plan_view = plan_view
	_refresh()


func toggle() -> void:
	enabled = not enabled
	_refresh()


func has_image() -> bool:
	return _has_image


func _refresh() -> void:
	visible = enabled and _plan_view and _has_image


func _build(underlay: Underlay, texture: Texture2D) -> void:
	var size := Vector2(texture.get_width(), texture.get_height()) * underlay.meters_per_px
	var plane := PlaneMesh.new()
	plane.size = size
	mesh = plane
	var material := StandardMaterial3D.new()
	material.shading_mode = BaseMaterial3D.SHADING_MODE_UNSHADED
	material.transparency = BaseMaterial3D.TRANSPARENCY_ALPHA
	material.albedo_texture = texture
	material.albedo_color = Color(1, 1, 1, OPACITY)
	material_override = material
	# PlaneMesh is centred; the underlay offset is the image's top-left corner.
	position = Vector3(underlay.offset.x + size.x / 2.0, HEIGHT, underlay.offset.y + size.y / 2.0)


static func _load_texture(image: String, project_path: String) -> Texture2D:
	var candidates := PackedStringArray()
	if project_path != "":
		candidates.append(project_path.get_base_dir().path_join(image))
	candidates.append(BUNDLED_DIR.path_join(image.get_file()))
	for path in candidates:
		if path.begins_with("res://"):
			if ResourceLoader.exists(path):
				return load(path) as Texture2D
		elif FileAccess.file_exists(path):
			var loaded := Image.load_from_file(path)
			if loaded != null:
				return ImageTexture.create_from_image(loaded)
	return null
```

```gdscript
## &"toggle_inspector", &"help", &"cutaway", &"zoom_in", &"zoom_out",
## &"zoom_reset", &"welcome", &"open", &"save", &"save_as", &"plan_view",
## &"orbit_view", &"underlay", &"measure", or &"" for none. Accepts the QWERTY and AZERTY variants.
static func action_for(event: InputEventKey) -> StringName:
	if not event.pressed or event.echo:
		return &""
	var character := char(event.unicode) if event.unicode > 0 else ""
	if event.is_command_or_control_pressed():
		if event.keycode == KEY_O:
			return &"welcome" if event.shift_pressed else &"open"
		if event.keycode == KEY_S:
			return &"save_as" if event.shift_pressed else &"save"
		if character in ["+", "="] or event.keycode in [KEY_PLUS, KEY_EQUAL, KEY_KP_ADD]:
			return &"zoom_in"
		if character == "-" or event.keycode in [KEY_MINUS, KEY_KP_SUBTRACT]:
			return &"zoom_out"
		if character == "0" or event.keycode in [KEY_0, KEY_KP_0] or event.physical_keycode == KEY_0:
			return &"zoom_reset"
		return &""
	if event.alt_pressed:
		return &""
	if character == "?" or event.keycode == KEY_F1:
		return &"help"
	match event.keycode:
		KEY_TAB:
			return &"plan_view"
		KEY_O:
			return &"orbit_view"
		KEY_P:
			return &"underlay"
		KEY_M:
			return &"measure"
		KEY_C:
			return &"toggle_catalog"
		KEY_I:
			return &"toggle_inspector"
		KEY_H:
			return &"cutaway"
	return &""

	return {"title": title, "entries": entries}
```
